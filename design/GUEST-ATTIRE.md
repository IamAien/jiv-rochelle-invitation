# Interactive wedding guests

The Dressed for love section now displays eight embroidered guests from the supplied `src/assets/colothes model` folders. Blue swatches update all four men's outfits; pink swatches update all four women's outfits. Each group retains its own last choice. Defaults are Misty Blue and Blush Pink. Reset returns both to those defaults; the color-code preview and copy action continue to follow the most recently selected shade.

The supplied images already include five outfit variants per person. [ATTIRE-ASSETS.json](ATTIRE-ASSETS.json) maps all 40 original PNGs to optimized runtime WebP files in `src/assets/attire-guests/`. Original source images remain in the user's workspace. Runtime versions preserve transparency, use height 960 and quality 90, and total about 4.6 MB across all 40 variants. No recoloring, image generation or redrawing was needed. Each person's variants are mapped by garment color; the right-facing main man's Cloud/French order and main woman's pink order differ from filename order.

The group is capped at 820 pixels wide (about 27% smaller than the first version). Guests alternate men and women, with a man and woman in the two center positions. Phones keep the same single-row lineup and two side-by-side color groups, scaled to fit. Only the people whose outfit changes crossfade over 650 milliseconds; the previous image stays mounted during the transition and is removed afterward. Initial images appear without an entrance animation. Reduced-motion settings show the new outfit immediately. Image changes prepare and decode the four affected outfits before committing them. Pointer hover and keyboard focus prepare the chosen group early. Separate request counters for men and women prevent a slower request from replacing a newer choice; reset and unmount invalidate pending selections. Picking one group commits against the latest combined selection, preserving the other group even when both are loading concurrently. Both active swatches remain marked, and the guest caption announces the two selections.

40 behavior tests pass, including independent suit/dress selection through repeated changes and coverage of every supplied outfit. Server-rendered checks cover all ten shade choices, verify all eight visible images and preserve the other group's selected color. Desktop, phone and selected-color still composites were visually inspected. The production build passes.
